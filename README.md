# FlowCanvas

AI 工作流创作首页交互原型，包含图片和视频工作流、案例素材前后对比、提示词自动填入、工作流改名及案例包导入导出。

## 本地运行

安装 Node.js 后，在项目目录执行：

```sh
node preview-server.cjs
```

打开 http://127.0.0.1:4173/ 。Windows 用户也可运行 `启动本地预览.ps1`。

入口文件：`ai_workflow_prototype_v7_auto_panel.html`。

案例数据保存在当前浏览器中。迁移素材、工作流名称和提示词模板，请在编辑状态导出 `.aicases` 案例包。此项目为交互原型，未接入真实 AI 生成服务。

详细操作参见 [使用说明](使用说明.md)，检查记录参见 [执行计划与验收](执行计划与验收.md)。

## 测试

`tests/` 包含浏览器验收脚本，当前使用开发环境的 Playwright 路径及 Microsoft Edge；在其他电脑运行时需配置对应依赖路径，并先启动本地预览服务。测试使用独立浏览器会话。
